# 会員数・収入算出の予算登録拡張

評価A（自己レビュー）。致命的0、改善推奨0。

従来は休会数・退会率のみ保存していたため、会員数・体験数・入退会数などが予算登録されなかった。会員系10項目と12か月を読み取り、既存の月次カード・年次予算に対応するカテゴリで保存する。客単価は円、人数は人、退会率は既存の整数百分率で保存する。紹介別内訳も保存する。

会員CSVは読み取れた店舗・年月・項目だけをトランザクションで更新。売上・経費CSVの再アップロードは当該CSVの費目だけを更新し、会員系予算を保持する。新しい人数カテゴリは年次経費の集計から除外した。DBスキーマ変更なし。

合成CSVと提供CSVを使ったモックAPIテストで120件・10項目・全12か月の対応を確認。前年9月と合計列の除外、TRUE/FALSE列、0、欠けた月・カテゴリの保持、別予算との分離、年度指定を検証。月次予算テストとNext webpackビルド（型チェック含む）成功。実CSVや値は公開リポジトリへ含めない。

本番DBへのCSV投入は行わない。新項目の登録には利用者による同じCSVの再アップロードが必要。
