# 予算CSV取込修正レビュー

評価: A（変更差分の自己レビュー）。致命的0・改善推奨0。

先頭空列のある予算書を読み取れず0件になる問題を修正。月ヘッダより左にある既知科目を照合し、賞与等の空白表記も正規化する。月の実列位置、既存の4列/月形式を保持し、合計・注記は集計しない。千円の小数を円換算時に切り捨てない。

ファイル名の対象年度と月ヘッダ直上の年が違う場合は400で返し、トランザクションに進まない。クライアント実CSVは2027/9期表題と2025年10月〜2026年9月見出しが矛盾しているため、対象年度回答待ち。原本の編集・本番への投入はしていない。

検証: 実CSVの年度不一致による保存停止、メモリ内だけで年見出しを合わせたシナリオの240件（科目20×12月）、旧4列形式、空列、賞与の空白、0予算、小数、対象店舗・年度の削除スコープ。型チェック・Next webpack build成功。

認証・権限、既存の削除範囲、DBスキーマは変更なし。APIテストはDBをモック化し、実CSVは環境変数指定時だけローカルから読み込み、公開リポジトリへ含めない。

公開後の認証付き実アップロードは、対象年度の確認と既存予算の上書き内容確認後に実施する。デプロイ成功と実データ取込完了を区別して報告する。
