1. ログイン方法

アクセス手順

  1. 1ブラウザで https://highalt-dashboard.vercel.app にアクセスします
  2. 2ログイン画面が表示されます
  3. 3管理者から発行された ユーザー名 と パスワード を入力します
  4. 4「ログイン」ボタンをクリックします

ユーザーの種類

ロール説明権限
管理者（admin）全店舗の閲覧・管理が可能全機能にアクセス可能
店長（store_manager）担当店舗の管理が可能自店舗のデータアップロード・閲覧、他店舗は閲覧のみ

セキュリティに関する注意

ログイン試行回数の制限: 5回連続でログインに失敗すると、15分間アカウントがロックされます。
セッションの有効期限: ログイン後24時間が経過すると自動的にログアウトされます。
パスワードは定期的に変更してください。

2. ダッシュボード画面の見方

ダッシュボードは店舗のPL（損益計算書）データを可視化する画面です。

2.1 期間選択

画面上部の期間選択エリアで、表示するデータの範囲を指定します。

  • 年度（決算年）: ハイアルチは10月始まりの会計年度です。「2026年度」は2025年10月〜2026年9月（9期）、「2027年度」は2026年10月〜2027年9月（10期）です
  • 期間: 「通期（10〜9月）」「上期（10〜3月）」「下期（4〜9月）」のほか、10月〜9月の各月（単月）を選べます
  • 単月表示のときの年: 年度で選んだ年と、実際のデータの暦年は異なる場合があります。たとえば「2027年度」の「10月」は、2026年10月のデータです（10〜12月は前の暦年、1〜9月は年度と同じ年）

2.2 店舗選択

  • ドロップダウンから対象店舗を選択します
  • 管理者は全7店舗（東日本橋、春日、船橋、巣鴨、祖師ヶ谷大蔵、下北沢、中目黒）から選択可能
  • 店長は自店舗がデフォルトで選択されます
  • 「本部（除外）」はPL計算の対象外です

2.4 グラフ

KPIカードの下に、データの推移や内訳を示すグラフが表示されます。

  • 売上推移 / 内訳: 会費・パーソナル・物販・その他の4分類に、自販機手数料収入を加えたものが売上合計です（内訳の合計は売上合計と一致します）。会費にはPayPay銀行への直接振込で受け取った会費等も含まれます。物販＝Squareのアイテム別売上の物販分類、パーソナル＝hacomono売上明細より集計、その他にはhacomonoのスポット等・手動追記の請求書・Squareの「サービス」「その他」分類が含まれます（画面に「サービス」という独立行はありません）
  • 客単価推移: 月会費売上 ÷ プラン契約者数（1人あたりの月会費収入）。予算を点線で重ねて表示
  • 人件費・経費・営業利益の推移: 各月の推移に予算を重ねて表示
  • 会員数系の推移: 在籍会員数（プラン契約者数）・新規入会数・退会数・退会率・入会率など
  • 入会率: 新規入会数 ÷ 体験者数。全体ビュー・月次ビューどちらでも表示され、店舗別の推移・予算線も確認できます（体験者数の算出方法は3.5「体験シート」参照）
  • 体験入会率: 体験シートの体験者のうち、入会した人（「即日入会」＋「後日入会」）の割合です。月次ビュー・全体ビューの両方に、入会率とは別のカードで表示されます。分母は体験シートの件数で、「検討中」「入会しない」は入会に数えません。体験シートがない月は「-」と表示されます。上の「入会率」（hacomonoの入会日時ベースの新規入会数 ÷ 体験者数）とは別の指標です
  • 前年比比較グラフ: 今期と前期を項目別（売上・人件費・広告宣伝費・消耗品費・営業利益）に並べて比較。「前年比◯%」を表示（全体・店舗別どちらでも表示されます）
  • 経費内訳: 勘定科目別の経費割合（福利厚生費は法定福利費と別の科目として集計されます）。減価償却費・開発費償却は現金の出入りがない費用のため、損益計算書の数値を2026年5月以降も含めて常に反映します（3.7参照）

※ 人件費・消耗品費・広告宣伝費・前年比は、クライアント様公式の損益計算書（前年比PLタブで取込）を正データとして表示します。

※ 売上には「自販機手数料収入」（PayPay銀行口座への自販機収益の入金分）も別建ての項目として含まれます。会費・パーソナル・物販・その他の4分類とは別経路の売上です。

※ オプション商品（例: HYROXオプション）は、設定画面の「オプション売上按分」に登録した商品について、売上を店舗間で付け替えて表示できます（4.8参照）。付け替えは集計時に行い、総売上・内訳の両方に同じ比率で反映されます。

2.5 全体表示と店舗比較

店舗セレクタで「全体」を選ぶと、全7店舗を合算した数値・グラフが表示されます。個別店舗を選ぶとその店舗のみの表示に切り替わります。

  • 売上、人件費、経費、営業利益、客単価、前年比などを全体／店舗別で確認可能
  • 店舗比較では全店舗のKPIを横並びで比較できます（管理者・マネージャーのみ）

2.6 体験者数の手入力カード

個別店舗の月次ビューには、体験者数・紹介経由の人数・その他売上を入力するカードがあります。

  • 体験者数の優先順位: 体験シートの実データ → 店長の手入力 → hacomono自動算出の順です。体験シートを取り込んだ月は、カードに「この月は体験シートの値が優先されます」と表示され、修正ボタンで手入力しても、他の集計画面では体験シートの値が使われます
  • 「差があります」の警告: 体験シートの人数と、手入力の人数が違うときに表示されます（例:「差があります（体験シート12人／手入力10人）」）。表示される数字は体験シートの値です。手入力が未入力のときは出ません
  • 「体験シートの記入漏れの可能性があります」の警告: 体験シートの人数が、hacomonoから自動算出した人数より少ないときに表示されます。体験シートへの記入漏れがないか、店舗で確認してください
  • いずれの警告も、確認を促すための表示で、数字そのものは変わりません。全体ビューでは表示されません（店舗ごとのビューで確認します）

2.7 アンケートと新規体験者属性

  • アンケート（認知経路・目的・頻度）: 選択した期間に入った回答だけを集計します。選んだ期間に回答がない、または回答内容が空の場合は、「この月（選択した期間）は、集計できるアンケート回答がありません」と表示され、累計の件数と最新の回答日が出ます。この店舗の回答が1件も取り込まれていないときだけ「アンケート回答が未取込です」と表示されます
  • 新規体験者属性（性別・年代）: 選択期間に体験日がある新規の方を集計します。月の初めなどで対象者がまだいない場合は「この期間に体験を受けた新規の方が、まだいません」と表示されます（データが取り込まれていないわけではありません）

3. アップロード画面

各種CSVファイルをアップロードしてデータを取り込みます。

3.1 共通の注意事項

対応形式: CSV（.csv）、Excel（.xlsx, .xls）
ファイルサイズ上限: 10MB
上書き: 既存データがある月にアップロードすると上書きされます（確認ダイアログあり）
アップロード履歴は自動的に記録されます。

3.2 人件費CSV

アップロード権限: 管理者のみ
  1. 1「アップロード」画面を開きます
  2. 2データ種別で「人件費」を選択します
  3. 3対象の年・月を指定します
  4. 4クラウド給与から出力した 支給控除一覧表（CSV/Excel）をアップロードします
  5. 5プレビュー画面で内容を確認し、「保存」をクリックします
自動処理:
従業員番号の千の位で店舗を自動判定（1xxx=東日本橋、2xxx=春日、...）
未登録の従業員がいる場合、店舗選択のアラートが表示されます。

3.3 経費CSV

経費データは2ステップでアップロードします。

ステップ1: Amazon注文履歴（オプション）

  1. 1Amazon注文履歴CSVを選択・アップロードします
  2. 2配送先住所から店舗が自動判定されます
  3. 3商品ごとの勘定科目が自動分類されます

Amazon注文履歴の取り込み（月1回・手動）: Amazon Businessの画面から、毎月1回CSVをダウンロードして取り込みます。自動ログインによる取得は行っていません。

  1. 1Amazon Businessにログインし、右上のアカウントメニューから「購買データ」→「レポート」→「注文履歴データ」を開きます
  2. 2期間を「先月」にして、「レポート（CSV）をダウンロードする」を押します（作成には数分かかります。完成したものは「ダウンロード履歴」からダウンロードします）
  3. 3ダッシュボードのアップロード画面の「Amazon（経費）」タブにCSVをドロップして、取り込みます
  • 取込は注文番号ごとの差し替えです。同じCSVを重ねて取り込んでも、二重にはなりません（他の注文には影響しません）
  • 取り込めていない月（抜け）がある場合は、「期間」を「過去12か月間」にしたCSVを1回取り込めば、まとめて補えます

ステップ2: PayPay銀行CSV

  1. 1PayPay銀行から出力した取引明細CSVをアップロードします
  2. 2システムが自動的に勘定科目の自動分類、AMAZON行のマッチング、収入取引の判定を処理します
  3. 3プレビュー画面で未分類の取引に手動で勘定科目を設定します
  4. 4手動で設定した勘定科目は 自動的にルールとして保存 され、次回以降は自動分類されます
  5. 5「保存」をクリックしてデータを確定します

3.4 hacomono（売上・アンケート・Square）

「hacomono（売上・アンケート）」タブに、hacomono / Square から出力した各種CSVをドロップします。ファイルの種類（会員ML001 / 売上明細PL001 / 月次サマリMA002 / 商品別売上PS001 / アンケート回答 / Square アイテム別売上）は自動で判別されます。複数ファイルをまとめて投入できます。

  1. 1「hacomono（売上・アンケート）」タブを選択します
  2. 2対象店舗を指定します（会員ML001・売上明細PL001・月次サマリMA002 は年月をCSVから自動認識。商品別売上PS001・Square アイテム別売上 はファイル名に年月が無いため、画面で年月を指定します）
  3. 3CSVファイルをドロップします（複数可）
  4. 4プレビューを確認後、保存します

Square アイテム別売上（物販の反映）

ダッシュボードの「物販」は、Square のアイテム別売上のうち「物販」に分類された商品（サプリ・ドリンク・ウェア・プロテイン・グッズ等）を集計して表示します。手順は上記 3.4 と同じで、Square から出力した「アイテム別売上」CSV を hacomono タブにドロップし、対象の年・月・店舗を指定して保存してください（ファイル名に「square」等が含まれていれば自動判別されます）。

  • 商品名またはカテゴリに「パーソナル / PT」→ パーソナル、「物販・サプリ・ドリンク・ウェア・タオル・プロテイン・グッズ・BCAA」→ 物販、として自動分類されます。
  • パーソナル売上は hacomono の売上明細から集計しています（Square のパーソナル分類は、二重計上を避けるため物販には含めていません）。
自動連携（手動アップロード不要）: hacomonoの会員（契約中・退会）・月別集計・売上一覧・商品別売上・アンケート回答・Squareアイテム別売上（連携済みの店舗）・決済手数料は、毎朝自動で取り込まれています。通常はこのタブを手動で操作する必要はありません（即時に反映させたい場合のみ、このタブから手動アップロードしてください。手動アップロードした分は自動連携の値を上書きします）。
・売上一覧・商品別売上は、毎朝「前月まるごと＋当月1日〜前日」を取り直します。当日分は反映されません（翌朝以降に入ります）。
・アンケート回答は（アンケートコード・年月）単位で取り込まれるため、期間を指定して集計すると、その期間のアンケート回答だけが正しく表示されます（表示のしかたは2.7参照）。
・自動取込が止まっていないかは、設定画面の「データ更新状況」（4.9）で確認できます。

3.5 体験シート

「体験シート」タブに、各店舗で運用している体験予約管理シート（Googleスプレッドシート）をCSVでエクスポートしてドロップします。

※ hacomono（会員ML001）には「最終的に入会した人」しか含まれないため、体験者数・入会率の分母が不正確になります。各店舗の体験シートを正データとして取り込むことで、体験者数を正確に反映します。

  1. 1「体験シート」タブを選択します
  2. 2店舗・対象年月を指定します（ファイル名から店舗・年月を自動検出し、初期値として入力されます。検出結果は画面に表示されるので、必ず内容を確認してください。誤っている場合は手動で修正できます）
  3. 3CSVファイルをドロップします（1店舗・1ヶ月につき1ファイル）
  4. 4内容を確認し、保存します
船橋店の特殊フォーマット: 船橋店のみ、体験シートの列名・列順が他店舗と大きく異なる専用フォーマットです。店舗選択で「船橋」を選ぶと、自動的に専用の解析処理に切り替わります。

体験者数・入会率の優先順位: ダッシュボードで使われる体験者数は、以下の優先順位で決まります。

  1. 1体験シート実データ（このタブで取り込んだ値）
  2. 2店長による手動追記（ダッシュボード画面の手動入力欄）
  3. 3hacomono自動算出（会員ML001由来・入会者のみのため参考値）

体験シートを取り込んだ店舗・月は、以降は体験シートの値が自動的に優先されます。

自動取込と手動取込: 巣鴨・中目黒・祖師ヶ谷大蔵・下北沢の4店舗は、体験シートが毎日自動で取り込まれます（このタブの操作は不要です）。東日本橋・船橋・春日は、当面、このタブから手動でCSVを取り込みます。

3.6 予算CSV

「予算」タブに、予算実績対比表の「予算書」CSV、または「販促報告」CSV をドロップします。店舗・年度・ファイルの種類は自動で判別されます（複数まとめて投入可）。

  1. 1「予算」タブを選択します
  2. 2CSVファイルをドロップします（ファイル名の「2026_9期（○○スタジオ）」から店舗・年度・期を自動判別）
  3. 3「解析して保存する」をクリックします

3.7 前年比PL（損益計算書・実績）

「前年比PL」タブに、予算実績対比表の「損益計算書」または「開業からの実績累計（PL）」CSV をドロップします。前年比比較や、経費（広告宣伝費・賃借料・電気料など）の正データとして使用します（原則2026年4月分までの反映）。

  1. 1「前年比PL」タブを選択します
  2. 2対象店舗を選び、その店舗のCSVを取り込みます
  3. 3「取り込む」をクリックします（既存データがある場合は上書き確認が出ます）

※ 減価償却費・開発費償却の例外（遡及反映）: この2費目は非資金支出（現金の出入りがない会計処理）のため、PayPay銀行CSV等の実データには現れません。「2026年4月分まで」のカットオフの例外として扱われ、このタブで取り込んだ損益計算書の数値が2026年5月以降も遡及して経費に反映されます。

3.8 手数料・電気料（一括取込）

「手数料・電気料」タブに、以下3種のファイルをまとめて1箇所にドロップできます。ファイルの種類は自動判別され、店舗別・月次の経費（支払手数料 / 電気料）に反映されます。

  • PAY.JP 決済手数料（店舗別サマリCSV）→ 支払手数料
  • fincode 決済手数料（取引明細CSV）→ 支払手数料
  • シンエナジー 電気料金明細（Excel）→ 電気料
自動連携（手動アップロード不要）:
・決済手数料（2026年8月分以降）: PAY.JP・fincodeの決済手数料は、hacomonoの売上データから自動集計され、毎朝取り込まれています。通常はこのタブを手動で操作する必要はありません（2026年7月分までは松尾様による手動投入データです）。
・電気料（シンエナジー）: シンエナジーの請求書（電気料金明細）を毎日自動で取得し、口座引落月に計上します（請求書の「N月分」は翌月の引落分のため、たとえば「8月分」は9月に計上されます）。同じ請求書は上書き、すでに別の登録がある店舗・月は二重にならないよう取り込まずスキップします。通常はこのタブを手動で操作する必要はありません（手動で取り込むことも引き続きできます）。

4. 設定画面

管理者・マネージャーはすべてのタブを使えます（「ユーザー管理」のロール・担当店舗の変更と「オプション売上按分」は、システム管理者のみ）。店長は「経費分類ルール」「Amazon商品マスタ」「従業員→店舗マッピング」の3つだけが表示されます。

4.1 従業員マッピング

従業員番号と所属店舗の対応関係を管理します。

  • 一覧表示: 登録済みの従業員マッピングが表示されます
  • 自動登録: 人件費CSVアップロード時に未登録の従業員が検出された場合、自動的に登録されます
  • 手動編集: 店舗の割り当てを手動で変更できます

4.2 経費分類ルール

PayPay銀行CSVの取引摘要に含まれるキーワードと勘定科目の対応ルールを管理します。

  • 勘定科目マスタ: 画面上部に勘定科目の一覧が表示されます（折りたたみ可）
  • CSVインポート: 「CSVインポート」ボタンから勘定科目マスタを一括で取り込めます
  • 一覧表示: 登録済みの経費分類ルール（キーワード→勘定科目）が表示されます
  • 新規追加: キーワードと勘定科目を指定してルールを追加できます
  • 自動学習: 経費アップロード時に手動分類した結果が自動的にルールとして保存されます
  • 削除: 不要なルールを削除できます

4.3 Amazon商品マスタ

Amazon注文履歴の商品と勘定科目の対応を管理します。

  • 一覧表示: 登録済みのASIN・商品名・勘定科目が表示されます
  • 検索: ASINまたは商品名で検索できます
  • 新規追加: ASIN、商品名、勘定科目を指定して登録します
  • CSV一括取込: 商品マスタCSVを一括でインポートできます
  • 削除: 不要な商品マスタを削除できます

4.4 ユーザー管理

管理者のみアクセス可能です。

  • ユーザー一覧: 登録済みのユーザーが表示されます
  • 新規追加: ユーザー名、パスワード、ロール（管理者 / マネージャー / 店長）、担当店舗を指定して作成します
  • マネージャー: 管理者と同等の権限を持つロールです（全店舗の閲覧・設定・アップロードが可能）
  • 編集（パスワード・表示名）: 既存ユーザーのパスワード・表示名を変更できます
  • 編集（ロール・担当店舗の変更）: 既存ユーザーのロール（店長⇄マネージャー）・担当店舗（店長の異動対応）を変更できます
  • 削除: ユーザーを削除できます（管理者ユーザーは削除できません）
ロール・担当店舗の変更は、システム管理者（admin）のみ実行できます。マネージャーが他人の権限を変更できてしまう事故を防ぐため、システム管理者としてログインした場合のみ、この変更欄が画面に表示されます（マネージャーには見えません）。

4.5 本部一括経費

管理者・マネージャーのみ。電気代・水道代・家賃など、本部で一括支払いし各店のPayPay銀行CSVに現れない経費を月次で入力します。

  • 計上先: 「本部一括」を選ぶと入力額を営業店舗数で均等按分。店舗名を選ぶとその店舗のみに計上します
  • 複数行: 同じ年月・費目・計上先でも、明細を分けて複数行を登録できます
  • 保存: 「行を追加」で入力し「保存」をクリックします

4.6 手動人件費

管理者・マネージャーのみ。クラウド給与の支給控除一覧表（CSV）に載らない社員（役員・業務委託・未登録者など）の給与総額を月次で登録します。登録額はその店舗・月の人件費に加算されます。

  • 入力項目: 月・店舗・氏名・雇用区分（正社員/アルバイト）・給与総額
  • 反映: 2026年4月以前は損益計算書の人件費を正とするため、加算は主に5月以降に反映されます

4.7 店舗名管理

管理者・マネージャーのみ。画面表示用の店舗名（表示名）を設定できます。

4.8 オプション売上按分

システム管理者のみ（マネージャーは使えません）。 特定のオプション商品の売上を、購入した会員の所属店舗から、別の店舗へ、決めた比率で付け替えて集計します（例: 他店の会員が購入した、下北沢のオプション商品の売上を、下北沢に計上する）。金額に直結するため、変更前に内容を確認してください。

  • 売上データそのものは書き換えません。 集計するときに付け替えるので、ルールを無効にしたり削除したりすれば、すぐ元の数字に戻ります。付け替えは総売上と内訳の両方に同じ比率で反映され、全体の売上合計は変わりません
  • ルールは何件でも（上限50件）追加・編集・無効化・削除できます。コードの変更は要りません
  • 商品名: 売上明細の摘要に含まれる商品名を入力します。全角・半角、スペースの違い、英字の大文字・小文字は区別せずに照合します。商品名の一部でも一致しますが、他の商品名にも含まれる短い名前にすると、意図しない商品まで按分されるため、3文字以上で、できるだけ具体的に入力してください
  • 按分先と比率: 1つのルールに、按分先の店舗を複数指定できます。比率（%）は按分先ごとに1〜100で、合計が100%までです。残りは、会員の所属店舗に残ります（例: 下北沢30%・中目黒20%なら、所属店舗に50%が残ります）。所属店舗と同じ店舗は、付け替えません
  • 開始年月: 2026年10月以降を指定します。それより前の月は変更されません
  • 有効にする: チェックを入れて保存したルールだけが集計に反映されます。有効にするには開始年月が必要です
  • 複数のルールが同じ売上に当てはまる場合: 商品名が最も長い（具体的な）ルール1件だけが適用されます（二重には按分されません）
  • 複数の商品が1行にまとまっている売上（入会時など）は按分できないため、元の店舗に残します。その件数は、画面上部の「按分できなかった売上（要確認）」に、年月・店舗別で表示されます。按分したい場合は、hacomono側で商品ごとに分けて取り込まれる必要があります

追加の手順:

  1. 1設定画面の「オプション売上按分」タブを開き、「ルールを追加」を押します
  2. 2商品名を入力します（例: 「HYROXオプション下北沢(月4回)」）
  3. 3按分先の店舗と比率を選びます（複数にする場合は「按分先を追加」）。画面に、按分の合計と、所属店舗に残る割合が表示されます
  4. 4開始年月を確認し、「有効にする」にチェックを入れて「保存」を押します
  5. 5ダッシュボードで、該当月の店舗別の売上を確認します（保存後、次に表示したときから反映されます）

例（数字は説明用）: 春日の会員が購入した「HYROXオプション下北沢(月4回)」6,000円に、「下北沢 50%」のルールを有効にすると、春日の売上が3,000円、下北沢の売上が3,000円になります（合計は6,000円のまま）。

やめたいとき: そのルールの「有効にする」を外して保存するか、「削除」を押します（削除すると確認が出ます）。

4.9 データ更新状況

管理者・マネージャーが使えます。 自動取込のデータが止まっていないかを、画面で確認できます。

  • 売上明細: 店舗ごとの、最新の売上日
  • 取込の記録: 売上一覧・商品別売上・会員・月別集計の店舗別の最終取込日、体験シート（4店舗）・アンケート・Squareの最終取込日
  • 電気料: 取り込み済みの最新の請求月
  • 日次の項目は、2日以上更新がないと赤い警告が出ます（電気料は、取り込み済みの最新月が3か月以上前のとき）。警告が出た項目は、一覧の上にまとめて表示されます
  • 売上明細は、数日間、売上の行が無い店舗があるため、警告が出ることがあります。続く場合は、hacomono側の売上と照合する必要があるため、システム管理者に連絡してください。他のデータも古くなっていないかを合わせて確認してください
  • 警告が続く場合は、システム管理者に連絡してください。復旧するまで、該当データを使った数字は古い可能性があります

5. FAQ（よくある質問）

ログインできない場合

Qパスワードを忘れた場合はどうすればよいですか？
管理者に連絡してパスワードのリセットを依頼してください。管理者がユーザー管理画面からパスワードを再設定できます。
Q「ログイン試行回数が上限に達しました」と表示されます
セキュリティのため、5回連続でログインに失敗するとアカウントが15分間ロックされます。15分後に再度お試しください。

データアップロードについて

QCSVファイルのエンコーディングはどれを使えばよいですか？
PayPay銀行CSVはShift_JIS（cp932）形式で出力されますが、システムが自動判定しますのでそのままアップロードしてください。UTF-8のCSVも対応しています。
Q同じ月のデータを再度アップロードできますか？
はい、可能です。既存データがある場合は上書き確認のダイアログが表示されます。「はい」を選択すると既存データが新しいデータに置き換わります。
Qアップロードしたデータを削除できますか？
同じ月に空のデータを上書きアップロードすることで実質的に削除できます。完全な削除が必要な場合は管理者にご相談ください。
Qファイルサイズが10MBを超えてアップロードできません
CSVファイルの場合、不要な列やヘッダー行を削除してファイルサイズを削減してください。それでも解決しない場合は管理者にご相談ください。

ダッシュボードについて

Qダッシュボードにデータが表示されません
以下を確認してください:
  1. 正しい年・月・店舗が選択されているか
  2. 対象期間のデータがアップロード済みか
  3. ブラウザのキャッシュをクリアして再読み込みしてみてください
Q人件費の内訳が表示されません
店長アカウントでは、他店舗の人件費内訳は閲覧できません。自店舗の内訳のみ表示されます。全店舗の内訳を確認するには管理者アカウントでログインしてください。
Q体験者数・入会率の数字が以前と変わりました
体験シート（3.5）を取り込んだ店舗・月は、その実データが最優先で使われるようになったためです。それ以前は、hacomonoの会員データ（入会者のみ）から算出した参考値を表示していたため、実際より少なく表示されていました。体験シートを取り込んでいない店舗・月は、従来どおり店長の手動入力またはhacomono自動算出の値が使われます。
Qhacomonoの売上・会員・アンケート、決済手数料、電気料、体験シートを毎回アップロードする必要がありますか？
いいえ。hacomonoのデータ（売上・会員・アンケート）と決済手数料（2026年8月分以降）は毎朝、電気料は毎日、体験シート（巣鴨・中目黒・祖師ヶ谷大蔵・下北沢）は毎日、自動で取り込まれます。通常は手動アップロードの必要はありません。まだ手動が必要なのは、Amazon・PayPay銀行・人件費・予算・前年比PL・体験シート（東日本橋・船橋・春日）です（3.9の一覧参照）。即時に反映させたい場合のみ、該当タブから手動でアップロードしてください（手動アップロードした分が優先されます）。
Q経費の勘定科目が「未分類」のままです
経費アップロード時のプレビュー画面で手動分類するか、設定画面の「経費分類ルール」で該当キーワードのルールを追加してください。一度手動分類すると、次回以降は自動分類されます。
Qオプション売上按分のルールを増やしたいときはどうしますか？
システム管理者が、設定画面の「オプション売上按分」タブで「ルールを追加」から登録できます（4.8参照）。商品名・按分先の店舗と比率・開始年月を入れて、「有効にする」にして保存します。コードの変更は要りません。
Qオプション売上を按分すると、売上データや全体の売上合計は変わりますか？
売上データ自体は変わらず、全体の売上合計も変わりません。集計のときに、店舗間で付け替えるだけです。ルールを無効にするか削除すれば、元の数字に戻ります。
Q按分したいのに、「按分できなかった売上」に出てきます
売上明細の1行に複数の商品がまとまっている（入会時など）場合は、どの商品の金額か分けられないため、按分せず元の店舗に残します。件数は設定画面の「オプション売上按分」の上部で確認できます。
Q「データ更新状況」に赤い警告が出ました
自動取込が止まっている、またはその項目のデータが古い可能性があります。システム管理者に連絡してください（4.9参照）。売上明細は、数日間売上の行が無い店舗で警告が出ることがあります。続く場合は、hacomono側の売上との照合が必要です。
Qアンケートの欄に「集計できるアンケート回答がありません」と出ます。取り込めていないのですか？
取り込めていないわけではありません。選んだ期間（月）の回答がない、または回答内容が空のときの表示で、累計の件数と最新の回答日が一緒に表示されます。アンケートは毎朝自動で取り込まれています。店舗の回答が1件も取り込まれていないときだけ「未取込」と表示されます。
Q「新規体験者属性」が「この期間に体験を受けた新規の方が、まだいません」と出ます
選択した期間に体験日がある新規の方が、まだいないときの表示です。月の初めなどによくあります。データが取り込まれていないわけではありません。
Q「体験入会率」と「入会率」は何が違いますか？
「体験入会率」は、体験シートの体験者のうち、入会した人（即日入会＋後日入会）の割合です。「入会率」は、hacomonoの入会日時をもとにした新規入会数 ÷ 体験者数です。算出元が違うため、数字は一致しないことがあります。
Q体験者数のカードに「差があります」「記入漏れの可能性」と出ます
「差があります」は体験シートの人数と手入力の人数が違うとき、「記入漏れの可能性」は体験シートの人数がhacomonoの自動算出より少ないときの確認用の表示です。数字は変わらず、体験シートの値が使われます（2.6参照）。体験シートの記入漏れがないか、店舗で確認してください。
Q2027年度の10月を選ぶと、どの月のデータが出ますか？
2026年10月のデータです。年度は10月始まりで、「2027年度」は2026年10月〜2027年9月（10期）です。10〜12月は前の暦年、1〜9月は年度と同じ年のデータになります（2.1参照）。
Q売上の内訳の合計が合わないように見えます
売上合計は、会費・パーソナル・物販・その他に、自販機手数料収入を加えたものです。会費にはPayPay銀行への直接振込の分も含まれ、Squareの「サービス」「その他」分類は「その他」に含まれます（2.4参照）。自販機手数料収入を含めて合計を確認してください。
QAmazonの注文履歴は自動で取り込まれますか？抜けている月があります
自動では取り込まれません。月1回、Amazon Businessの「購買データ」→「レポート」→「注文履歴データ」で「先月」のCSVをダウンロードして、「Amazon（経費）」タブから取り込みます（3.3参照）。取り込めていない月は、「過去12か月間」のCSVを1回取り込めば補えます。注文番号ごとの差し替えのため、重ねて取り込んでも二重にはなりません。

その他

Q複数のブラウザやデバイスから同時にログインできますか？
はい、可能です。ただし、それぞれのセッションは独立しており、一方でログアウトしても他方には影響しません。
Q対応しているブラウザは何ですか？
Google Chrome、Mozilla Firefox、Microsoft Edge、Safariの最新版に対応しています。Internet Explorerには対応していません。
Q操作中にエラーが発生した場合はどうすればよいですか？
ブラウザを再読み込みして再度お試しください。問題が解決しない場合は、エラーメッセージのスクリーンショットとともに管理者にご連絡ください。
