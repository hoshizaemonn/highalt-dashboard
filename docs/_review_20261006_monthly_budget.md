# 月次予算表示 レビュー

評価: A（変更差分の自己レビュー。本番のログイン後確認は別途）。

- 目的: 各店舗の単月画面に登録済み予算・実績・差額・予算比を表示する。
- DB: 読取済みの月次レスポンスのみ利用。取込・書込・スキーマ変更なし。
- 認可: 個別店舗表示に限定。給与明細は表示せず、既存KPIカードと同じ人件費合計のみ。
- 金額: 体験数・会員数・率・客単価を経費に混ぜない。売上の旧分類と4分類の二重計上を避ける。
- 実績: 売上・経費・人件費・利益は既存月次KPIカードと同じ値を渡す（PLによる人件費補正を含む）。
- 表示: 未設定と0円を区別。0以下の予算比は非表示。退会率の差はpt。経費・退会の増加は不利として表示。
- 検証: TypeScript、変更追加ファイルESLint、diffチェック成功。計算・SSR回帰試験成功。本番DBの9期7店舗×12ヶ月=84組で各財務予算合計を生成可能と確認。
- 見た目: ローカルHTMLでPCと狭幅を確認。表だけが横スクロールし、ページ全体には横はみ出しなし。
- 既存事項: MonthlyView内の以前からあるsetPlComp(null)にreact-hooks/set-state-in-effectのlintエラーあり。今回の追加コードはエラーなし。
- 出荷確認: ユーザーの月次表示追加依頼と本番反映の承認に基づく。CSVは山本様担当のため投入しない。
