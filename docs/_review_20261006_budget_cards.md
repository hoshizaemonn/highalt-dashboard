# カード内予算表示 レビュー

評価: A（変更差分の自己レビュー）。
目的: 月次の比較表を削除し、既存の売上・人件費・経費・利益・体験・入会などのカード/項目内に予算を表示する。
実績の大きな値と既存の前年比は維持し、予算と予算比を下に追加。予算未設定と0を区別し、0以下の予算比は出さない。
予算を指定しない他画面のKPICardは従来どおり。人数/率/金額の単位を分離。既存の表示/編集権限と取込処理は変更しない。
確認: SSRカード試験（未設定、0、人数、費用の色判定、従来カード互換）、9期7店舗×12ヶ月予算計算、型チェック、新規コンポーネントlint、diffチェック。PC/狭幅のカードプレビューを目視確認。
旧比較表コンポーネントと参照は削除。本番DB書込・CSV投入なし。
本番ログイン後の目視は別途（手元の認証情報が無効）。
